## Part 2 — cost in OpenChamber Agent Groups (per agent)

**Problem**: the title suffix works for one-off sessions, but OpenChamber's
Agent Manager ("Agent Groups", the multi-run view) never renders session
titles or cost — it only shows group name, model count, branch, and a
`provider/model` dropdown (verified in `AgentGroupDetail.tsx` /
`AgentManagerSidebar.tsx` of `openchamber@2.0.2` source). So the plugin alone
can't surface cost there.

**Solution**: a small OpenChamber **extension** (guest panel) at
`.opencode/extensions/group-costs/` — the supported extension point (docs:
docs.openchamber.dev/sdk). It:

- declares `capabilities: ["sessions"]` and uses the guest SDK wire protocol
  (`openchamber.sdk` v1: `hello` → `ready` → `workspace-subscribe` for
  projects + sessions), hand-implemented as a classic IIFE in `panel/main.js`
  (no bundler needed; guests can't load ESM).
- reads live session titles (which the cost-title plugin enriches), strips the
  `· $X.XX · Nk tok` suffix, and re-parses OpenChamber's multi-run title
  format `groupSlug/[gN/]provider/model[/index|fusion]` (a port of
  `parseMultiRunSessionTitle` from the OpenChamber source) to rebuild the
  groups.
- renders **both** asked-for views: per-group totals (`$15.55 · 1.4M tok ·
  2 runs`, `+` when some runs have no cost yet) and **per-agent rows**
  (provider/model, branch, activity dot, outcome, cost, tokens), each row
  clickable via `open-session`. Non-group sessions appear under "Other
  sessions". Archived and child sessions are excluded.
- follows the host theme (`applyTheme` from the `ready` payload) and the
  open-project switch (`directory` pushes, project selector when >1 project).

Manifest: `panel` (rail icon `bar-chart-2`) + `page: true` (full-screen from
the Extension pages menu), `engines.openchamber >=2.0.0`.

**Install**: already done — registered against the live OpenChamber
(`http://127.0.0.1:3000`) via `POST /api/guests` (folder path) and the
`sessions` capability granted via `PUT /api/guests/group-costs/capabilities`.
`GET /api/guests` confirms: `enabled: true`, `granted: ["sessions"]`, and both
panel assets serve 200 from `/api/guests/group-costs/panel/*`. To re-add from
the UI instead: Settings → Extensions → paste the absolute folder path
`/home/coder/HomeAssistant/.opencode/extensions/group-costs`. Folder installs
run in place, so edits are picked up on panel reload.

**Validation**: mock-host harness (`/tmp/opencode/gc-test/`, scratch) served
over HTTP and driven with Playwright — the panel completed the full protocol
handshake against a simulated host, subscribed to projects+sessions, and
rendered two fixture groups with correct per-agent costs, totals, `+`
partial-cost marker, runGroup parsing (`refactor · g1`), ungrouped section,
and child/archived filtering. `node --check` on main.js; manifest fields
validated against `@openchamber/sdk` parse schema.

**Limitations** (by design of the guest API): the SDK's session records carry
`title` but not `cost`/`tokens`/`metadata`, so the extension parses cost from
the title the plugin maintains. Runs that finished before the plugin was
loaded (or sessions the plugin skipped) show `—`. If a future OpenChamber
exposes cost in the guest snapshot, swap the parser for the real fields.

## What

New OpenCode V2 **server plugin** at `.opencode/plugin/cost-title.ts`
(id `local.cost-title`). After every finished turn it appends the session's
running cost and token total to its title — e.g. `Fix locks · $1.23 · 45k tok`
— so cost stays visible in OpenChamber (VS Code panel, web, desktop) and the
TUI without any dashboard work.

Optional env knobs (read by the **service process**, so they need a service
restart to change):

- `COST_TITLE_DEBUG=1` — log every event type the plugin sees (server log).
- `COST_TITLE_WARN_USD=5` — prefix `⚠ ` on sessions costing ≥ $5.

## Behavior

- Listens on the server-global event stream and acts on:
  - `session.execution.succeeded` / `.failed` / `.interrupted` — any finished
    turn spent money, so all three get titled.
  - `session.renamed` — catches the auto-generated title that lands *after*
    the first turn finished, and re-suffixes manual renames. Idempotent: the
    plugin's own rename re-fires the event, re-computes the same title, no-op.
  - `session.usage.updated` — caches fresh cost/token totals as a fallback.
  - `session.deleted` — prunes the cache.
- Titles only **root** sessions (skips `parentID` subagent sessions), skips
  untitled / `New session` placeholders, and is **scoped to this project**
  (`Session.Info.projectID` match, directory-prefix fallback) — the shared
  background service streams events for every project on this machine.
- Suffix format: ` · $<cost.toFixed(2)> · <tokens> tok`, tokens as
  `999` / `45k` / `6.0M` (input+output+reasoning+cache read+write).
